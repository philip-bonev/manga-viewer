# Manga Viewer

A lightweight desktop manga and comic reader built with **Tauri 2**, a **Rust** backend and a
plain **HTML/CSS/JavaScript** frontend (no frameworks, no bundler, no `node_modules`).

The app is designed around continuous vertical scrolling: open an archive and read, with
images lazy-loaded around the viewport so even very long chapters stay fast and memory-light.

## Features

- **Archive formats**: `.cbz` (ZIP), `.cbt` (TAR), `.cb7` (7z, including solid archives).
- **Image formats**: JPEG, PNG, GIF, WebP, BMP, SVG, TIFF.
- **Continuous vertical scroll** with lazy loading (pages near the viewport are fetched on
  demand from the Rust backend as base64 data URLs).
- **Zoom**: 25 % – 500 % in 25 % steps, fit-to-width reset, toolbar buttons, `Ctrl` + mouse
  wheel, and keyboard shortcuts (`+` / `=` zoom in, `-` zoom out, `0` reset, `Esc` closes
  dialogs).
- **Page counter** showing loaded pages / total pages.
- **Series navigation**: `Prev` / `Next` jump to the neighbouring issue in the same folder.
  Files are matched by the naming pattern `Series Name-<number>` or `Series Name_<number>`
  (e.g. `Berserk-001.cbz` → `Berserk-002.cbz`), with numeric (not lexicographic) ordering.
- **Multiple ways to open a file**: Open dialog, drag & drop onto the window, command-line
  argument (`manga-viewer path/to/issue.cbz`), and OS file associations for `.cbz`, `.cbt`
  and `.cb7`.
- **Single instance**: launching the app again with a file reuses the running window instead
  of starting a second one.
- **Window state persistence**: size and position are restored between sessions.
- **About dialog** with version, build date, author, license text and repository link.

## Tech stack

| Layer     | Technology                                                                  |
| --------- | --------------------------------------------------------------------------- |
| Shell     | [Tauri 2](https://tauri.app) (Rust)                                          |
| Backend   | Rust — archive reading (`zip`, `tar`, `sevenz-rust`), Tauri commands          |
| Frontend  | Vanilla HTML / CSS / ES modules in `web/`, served directly (`frontendDist`)   |
| Plugins   | `dialog`, `fs`, `opener`, `single-instance`, `window-state`                   |

There is no frontend build step: `tauri.conf.json` points `build.frontendDist` straight at
the static `web/` directory, and the frontend accesses Tauri through `window.__TAURI__`
(`withGlobalTauri` is enabled).

## Requirements (mandatory for compiling)

The project is a pure Rust crate — **Node.js / npm / pnpm are NOT required**. You need:

1. **Rust stable toolchain ≥ 1.85** — the crate uses **edition 2024**.
   Install via [rustup](https://rustup.rs):
   ```sh
   curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
   rustup update stable
   ```
2. **Tauri CLI 2.x** — used to drive dev/build:
   ```sh
   cargo install tauri-cli --version "^2"
   ```
   (Verified against `tauri-cli 2.11.5` / `tauri 2.12`.)
3. **Platform dependencies of Tauri**:
   - **Linux** — WebKitGTK 4.1 and build tooling (Debian/Ubuntu):
     ```sh
     sudo apt update
     sudo apt install libwebkit2gtk-4.1-dev libjavascriptcoregtk-4.1-dev \
       build-essential curl wget file libxdo-dev libssl-dev \
       libayatana-appindicator3-dev librsvg2-dev
     ```
   - **macOS** — Xcode Command Line Tools (`xcode-select --install`); uses the system
     WKWebView.
   - **Windows** — MSVC Build Tools (Visual Studio with the “Desktop development with C++
     workload”) and the [WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/)
     (preinstalled on Windows 10/11).
4. **The `LICENSE` file must stay at the repository root** — `src/lib.rs` embeds it at
   compile time via `include_str!("../LICENSE")` for the About dialog. Compiling will fail
   without it.

Note: `build.rs` stamps the build date into the binary automatically (`BUILD_DATE`), and
`gen/schemas/` is generated by `tauri-build` on first compile — neither needs manual setup.

## Building

```sh
# Development build with hot reload (opens DevTools in debug builds)
cargo tauri dev

# Production build + platform bundle (.app/.dmg, .deb, .msi/.exe, …)
cargo tauri build
```

Bundled artefacts are placed under `target/release/bundle/`.

### Debian packages

`tauri.conf.json` ships a `.deb` configuration that registers the comic MIME types
(`mime/comicbook-mime.xml`) and runs `scripts/postinst` / `scripts/prerm` to refresh the
system MIME database, so `.cbz` / `.cbt` / `.cb7` files open with the app after install.

## Backend commands (Tauri IPC)

| Command                        | Purpose                                                     |
| ------------------------------ | ----------------------------------------------------------- |
| `open_cbz_file(path)`          | List images in a ZIP archive and mark it as current file     |
| `open_cbt_file(path)`          | List images in a TAR archive and mark it as current file     |
| `open_cb7_file(path)`          | List images in a 7z archive and mark it as current file      |
| `get_image_data(href)`         | Read one image from the open archive as base64                |
| `get_next_file(path)` / `get_prev_file(path)` | Series-aware neighbour issue lookup            |
| `get_cli_file()`               | Path passed on the command line / via OS "open with"         |
| `close_file()`                 | Release the currently opened archive                         |
| `get_app_info()`               | Name, version, build date, license text, repository          |
| `exit_app()`                   | Quit the application                                         |

Images are always streamed from Rust to the webview on demand — nothing is extracted to
disk, and the frontend discards data URLs when pages leave the lazy-load window.

## Usage

- **Open** — toolbar button, drag & drop a file onto the window, or double-click an
  associated `.cbz` / `.cbt` / `.cb7` file.
- **Navigate issues** — `Prev` / `Next` in the toolbar (enabled only when a matching
  neighbour file exists next to the current one).
- **Zoom** — `+`, `-`, `0`, the toolbar zoom buttons, or `Ctrl` + mouse wheel.
- **About** — version, build date and the full Apache license text.
